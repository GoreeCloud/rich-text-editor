# GoreeCloud Rich Text Editor

Aplicación de notas local para escritorio, editor y visor de Markdown y editor de texto enriquecido.

Esta es una importación con nueva marca del proyecto [Quiet.md](https://github.com/s1dashu/quiet-md). El código fuente original y su versión exacta se indican en [UPSTREAM.md](UPSTREAM.md).

Permite editar archivos Markdown, importar carpetas y exportar a Markdown o PDF. Los documentos permanecen en el equipo. Algunas notas utilizan el formato Feishu/Lark DocxXML, no Markdown.

**Estado:** beta de código fuente; aún no hay instaladores ni actualizaciones oficiales de GoreeCloud. Consulte [README.md](README.md) para compilación y licencias.
