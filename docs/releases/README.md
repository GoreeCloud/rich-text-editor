# Historical upstream release notes

The documents in this directory were imported from the original
[Quiet.md project](https://github.com/s1dashu/quiet-md) for attribution and
historical context. Their legacy download commands, release numbers, and
upstream links are **not GoreeCloud Rich Text Editor releases**.

GoreeCloud release candidates must instead pass the
[release readiness checklist](../RELEASE_READINESS.md) and
[release operations runbook](../RELEASE_OPERATIONS.md). No independently
signed GoreeCloud installer is currently published by this repository.
