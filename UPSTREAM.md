# Rebranded Import provenance

**GoreeCloud Notes** (initially branded **GoreeCloud Rich Text Editor**) was imported from [Quiet.md](https://github.com/s1dashu/quiet-md) by s1dashu.

- Upstream repository: https://github.com/s1dashu/quiet-md
- Imported branch: main
- Imported commit: fa62760d1ca1753608c5bda4e89df0a435476594
- Import date: 2026-11-13
- Import commit label: Rebranded Import

The rebrand changes visible product names, package identifiers, installer metadata, storage and log paths, README, and other relevant build scripts. No release signing or update service has been configured for GoreeCloud; in-app update checks are disabled for safety.

The original upstream MIT license and third-party attribution file are retained. Upstream's separately licensed Nucleo UI icons were replaced with ISC-licensed Lucide SVGs and the original branding artwork was removed. The original upstream project, authorship and contributions are still acknowledged.

This is a source import, not a claim that the app has been packaged and tested on every supported platform.

On November 13–14, 2026, the founder renamed the product to **GoreeCloud Notes** and established `GoreeCloud/notes` as its source repository. The upstream commit, license, original attribution, and Git history remain unchanged by the product-name update. Existing library paths and internal package identities are preserved until migration tests validate a later transition.
