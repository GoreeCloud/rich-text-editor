# GoreeCloud Rich Text Editor

本地优先的桌面笔记应用、Markdown 编辑器与查看器、富文本编辑器。

这是基于 [Quiet.md](https://github.com/s1dashu/quiet-md) 的 main 分支进行的品牌重构导入。原始提交记录见 [UPSTREAM.md](UPSTREAM.md)。

支持直接编辑 Markdown 文件、导入文件夹，以及导出 Markdown 和 PDF。笔记保存在本机。部分文档采用飞书/Lark DocxXML 格式，而不是 Markdown。

**状态：** Beta 源码导入，目前尚未发布 GoreeCloud 官方安装包或自动更新。构建说明、许可证和署名详见 [README.md](README.md)。
