# GoreeCloud Rich Text Editor

ローカルファーストのデスクトップノートアプリ、Markdown エディター／ビューアー、リッチテキストエディターです。

[Quiet.md](https://github.com/s1dashu/quiet-md) の main ブランチからリブランドしたソースコードです。元のコミットは [UPSTREAM.md](UPSTREAM.md) に記載しています。

Markdown ファイルの直接編集、フォルダーの読み込み、Markdown・PDF への書き出しに対応しています。データはローカルに保存されます。一部のノートは Markdown ではなく Feishu/Lark DocxXML 形式です。

**状態:** ベータ版ソースのインポートです。GoreeCloud の公式インストーラーや自動更新はまだありません。ビルド方法とライセンスは [README.md](README.md) を参照してください。
